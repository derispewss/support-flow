# Changelog

## [0.1.0] - 2026-11-03

### Added

- Multi-tenant customer support portal with tickets, messages, attachments, watchers, SLA policies, and audit logs.
- Agent/admin console with queue, ticket detail, master data, members, reporting, and CSV export.
- Public knowledge base with article search, voting, sitemap, and robots.txt.
- Queued notifications, SLA checks, signed webhooks, delivery retries, and delivery logs.
- Plan-based API throttling, upload throttling, cursor pagination, and MySQL FULLTEXT search with SQLite fallback.
- Demo seeder accounts, tickets, knowledge base article, and webhook.

### Quality

- 150+ automated tests covering authentication, tenancy, support workflows, automation, reporting, and hardening.
- Pint, PHPStan, Scramble, and GitHub Actions CI configuration.
